NGINX released fixes for five CVEs (CVE-2026-123007, CVE-2026-123634, CVE-2026-123633, CVE-2026-121810, CVE-2026-113425) affecting HTTP/2, resolver, HTTP/3, and mail proxy modules in versions 1.9.5–1.31.8, with potential remote code execution impact. Fixed in mainline 1.31.9 and stable 1.30.7. This Splunk advisory points to the NGINX fixes but lacks technical details on root causes or exploitation; Splunk is still investigating impact to its own products.
