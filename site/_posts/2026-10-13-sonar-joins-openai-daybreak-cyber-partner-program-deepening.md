Sonar integrated OpenAI's frontier GPT-6.1 Sol model into SonarQube Hunter Agent via the OpenAI Daybreak Defense Network, improving logic-flaw detection coverage from 47% to 67% (+20%) and reducing scan time by 43% on large codebases through prompt caching. Hunter Agent uses structured security playbooks paired with advanced reasoning to detect flaws that pattern-matching misses—including permission-check bypasses (IDOR-like issues) and unsafe agent skill modifications that could remove approval steps or leak credentials. The partnership reflects the tightening window defenders have as exploitation timelines compress; frontier AI reasoning capability is now available defensively for code verification in the agentic era.
