A detailed CTF writeup demonstrating a multi-stage Windows domain compromise. Starting with weak credentials in a Gitea instance, the attacker exploits a Python eval RCE in an outdated pgAdmin installation to escape into a containerized environment. Lateral movement through Docker API abuse and certificate forgery—combined with ADCS misconfigurations (ESC1-style attacks)—enables privilege escalation on the Hyper-V host. The attack chain leverages GMSA password enumeration and Kerberos abuse to ultimately compromise the domain controller, illustrating chained misconfigurations in real-world Active Directory environments.
