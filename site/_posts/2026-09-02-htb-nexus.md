A Hack The Box write-up demonstrating a multi-stage exploitation chain on a Krayin CRM system. Initial access recovers credentials from a public Gitea repository, enabling authenticated login and exploitation of a TinyMCE file upload vulnerability for webshell deployment. Privilege escalation chains Git's permissive safe.directory setting with unsanitized path handling in a root-level template sync script to achieve directory traversal via poisoned Gitea tree objects and arbitrary file write. The write-up also covers an unauthenticated installer bypass and Laravel debug bar information leakage, illustrating how multiple small misconfigurations combine into complete system compromise.
