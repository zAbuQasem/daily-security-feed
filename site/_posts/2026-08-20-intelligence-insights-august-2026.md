Red Canary's July 2026 threat report tracks the prevalence of 12 distinct malware families and activity clusters across customer environments. ClearFake remains #1 for the fourth consecutive month—a JavaScript injection technique delivering drive-by malware via fake CAPTCHA lures using malicious copy-paste attacks. Notable debuts include GraphSpy, an open-source Entra ID/Microsoft 365 exploitation tool running a browser-based GUI that centralizes device code phishing, primary refresh token theft, Windows Hello for Business key registration, MFA manipulation, and data exfiltration from SharePoint, OneDrive, Outlook, and Teams; EtherRAT, a Node.js-based RAT using blockchain-based C2 resolution with credential theft and lateral movement modules; and Phexia, a macOS RAT/stealer hybrid. The report provides technical descriptions of each threat and mitigation recommendations, with specific guidance on Conditional Access policies to restrict device code authentication flows.
