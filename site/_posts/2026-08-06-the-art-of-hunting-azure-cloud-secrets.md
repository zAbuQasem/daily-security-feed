TrustedSec releases Microburst Secrets Hunter, a tool that automates post-exploitation secret discovery from Azure Microburst enumeration output, scanning logic applications, VM extensions, automation accounts, and deployment logs for exposed credentials that could enable privilege escalation. Secrets Stalker complements this by validating discovered client secrets against Azure and Graph API endpoints to determine the true access scope of compromised service principals without noisy large-scale enumeration. Both tools reduce manual discovery overhead in Azure penetration tests, with support for CSV and HTML reporting with configurable redaction for safe client delivery.
