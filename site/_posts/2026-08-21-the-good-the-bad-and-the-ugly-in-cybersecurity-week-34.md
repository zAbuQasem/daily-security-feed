A weekly security digest covering three significant threats: (1) The U.S. indicted 17 Iranian nationals from the Mabna Institute for a state-sponsored cyber espionage campaign operating since 2013, compromising 80,000+ academic credentials and exfiltrating 31 TB of data from 178 universities and 53 private firms. (2) CISA advisory warns of the Medusa ransomware RaaS syndicate, which has compromised 500+ critical infrastructure organizations across healthcare, manufacturing, defense, and financial sectors using double-extortion tactics and an aggressive affiliate program paying $100–$1M for initial access. (3) CVE-2026-33824, a critical unauthenticated remote code execution vulnerability in Windows IKE (Internet Key Exchange), affects all supported Windows 10, 11, and Server 2016–2025 via a double-free flaw exploitable through malicious UDP packets on ports 500/4500, now actively exploited in the wild.
