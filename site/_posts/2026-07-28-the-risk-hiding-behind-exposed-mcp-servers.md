Wiz research identifies security risks arising from exposed Model Context Protocol (MCP) servers in cloud environments. MCP is a protocol enabling AI models to access external systems via standardized interfaces; exposing servers without proper access controls can allow unauthorized model interactions with sensitive cloud resources, databases, and tooling. The article examines how misconfigured MCP deployments in production environments create a new attack surface for cloud infrastructure compromise, particularly as AI adoption accelerates in enterprise cloud workloads.
