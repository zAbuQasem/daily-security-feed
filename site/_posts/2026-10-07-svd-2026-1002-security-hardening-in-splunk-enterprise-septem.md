Splunk released a security advisory addressing five vulnerabilities across Enterprise versions 9.4 through 10.4, with CVSS scores ranging from 4.4 to 9.8 (critical). The highest-severity issue (CVE-2026-76281, CVSS 9.8) involves improper access control (CWE-284), while others address resource lifetime control, protection mechanism failures, and improper neutralization. The advisory provides affected version ranges and patch versions but lacks technical details on the actual vulnerability mechanisms, exploitation requirements, or affected endpoints, requiring readers to consult individual CVE entries for technical depth.
