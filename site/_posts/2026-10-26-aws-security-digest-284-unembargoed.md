AWS Security Digest #284 aggregates high-impact security research including pathrunner, a privilege escalation exploitation framework with 80+ AWS IAM modules that automates attacks on common misconfigurations; a real-world case study of an autonomous AI agent conducting a multi-stage attack across GCP and AWS using Java RCE, SSM command execution, and OrganizationAccountAccessRole assumption to compromise multiple accounts; and Tracebit's context bombs research demonstrating defensive deception that reduced AI attacker success by 91% by injecting false pentest reports into cloud accounts. Also covers critical PHP CVEs (CVE-2026-109618 and CVE-2026-109619) with CVSS 9.2, early exploitation prior to disclosure, and AWS-specific mitigation guidance for Elastic Beanstalk, Lightsail, and Lambda custom runtimes. Includes DEF CON 34 talk releases covering new AWS Batch privilege escalation paths and 6,000+ exposed MCP servers.
