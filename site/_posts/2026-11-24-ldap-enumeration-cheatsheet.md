Comprehensive LDAP enumeration methodology for Windows Active Directory assessments, organized as a practical checklist covering base enumeration, Kerberoasting and AS-REP roasting, gMSA password extraction, ADCS configuration review, BloodHound relationship mapping, and writable object discovery. Provides specific netexec, bloodyAD, certipy, and RustHound commands with example outputs and configuration notes (LDAP signing/channel binding detection). Includes unauthenticated enumeration techniques and background on LDAP protocol structure (DNs, attributes, Global Catalog servers on ports 389/636/3268-3269). Useful reference for systematically mapping AD domains and identifying privilege escalation paths during authorized assessments.
