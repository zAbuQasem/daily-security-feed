Microsoft's October 2026 Patch Tuesday addresses 1415 vulnerabilities, including 85 critical with 67 being RCEs. One vulnerability (CVE-2026-96951, command injection in Windows Shell, CVSS 8.8) is actively exploited in the wild. Critical RCEs include Active Directory Domain Services (CVE-2026-70229, incorrect authorization, 8.1 CVSS), Exchange Server (CVE-2026-70571, stack buffer overflow, 8.1 CVSS), and maximum-severity flaws in QUIC (9.8 CVSS) and Message Queuing (9.8 CVSS). Additional concerns include 18 distinct Excel RCE vulnerabilities (mostly 8.8 CVSS with buffer overflow and use-after-free weaknesses) and multiple Hyper-V escapes via memory bugs.
