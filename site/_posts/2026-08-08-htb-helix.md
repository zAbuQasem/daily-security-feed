HTB Helix is a CTF write-up demonstrating exploitation of Apache NiFi via the H2 database driver, which can execute arbitrary Java code when scripts are run on connection. The author gains initial RCE on an anonymously-accessible NiFi instance, pivots through SSH keys, and chains a privilege escalation involving temporal access control (a maintenance console that only runs during maintenance windows). The final privilege escalation involves tampering with a chemical reactor's control server by manipulating calibration offsets to trigger temperature thresholds that open the maintenance window. The write-up includes detailed reconnaissance with nmap/ffuf and demonstrates practical exploitation of real vulnerabilities in industrial control and data pipeline scenarios.
