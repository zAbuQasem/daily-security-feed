Doyensec has open-sourced ElectroNG, a static application security testing (SAST) tool for Electron applications, under the Apache License 2.0. ElectroNG enhances the earlier command-line Electronegativity tool with improved AST and DOM analysis, ~60 security checks, a database of 650+ known Electron vulnerabilities, version-aware detection, and a desktop application for project management and triage. The tool performs HTML, JavaScript, and TypeScript parsing to identify misconfigurations and security anti-patterns across BrowserWindow and BrowserView settings. The codebase is available in two repositories (ElectroNG desktop app and ElectroNG-core scanning engine) and actively seeks community contributions to modernize detection for current Electron versions and reduce false positives.
