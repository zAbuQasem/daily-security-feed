Wiz researchers identified multiple critical vulnerabilities in LiteLLM, an open-source proxy for LLM APIs, leading from authentication bypass to cloud infrastructure compromise. The vulnerabilities enable remote code execution and credential theft, with evidence of active exploitation in production AI deployments. The research demonstrates how weaknesses in widely-used AI framework proxies can cascade into supply-chain-level cloud attacks affecting downstream applications leveraging LiteLLM as an integration layer.
