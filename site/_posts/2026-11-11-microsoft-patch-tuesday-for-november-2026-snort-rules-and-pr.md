Microsoft's November 2026 Patch Tuesday addresses 1,095 vulnerabilities, including 64 critical ones with 48 being remote code execution flaws. High-impact vulnerabilities include Active Directory Domain Services RCEs (CVE-2026-118146: incorrect authorization, CVSS 8.8; CVE-2026-118148: elevation of privilege, CVSS 7.5), Microsoft Exchange Server RCE (CVE-2026-118207: name resolution issue, CVSS 8.8), Windows NAT RCE (CVE-2026-113862: use-after-free, CVSS 8.1), and Schannel RCE (CVE-2026-119952: timing discrepancy, CVSS 8.1). One vulnerability is already being exploited in the wild. Additional critical RCEs affect Office applications (Outlook, Word) and Windows components including Hyper-V and Print Spooler.
